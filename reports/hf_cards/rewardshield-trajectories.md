# RewardShield: agent trajectories

Multi-turn tool-calling trajectories of Tiny Aya Global (3B) and four LoRA adapters of it answering Spider
questions with one `run_sql` tool, in AgentTune's Tiny Aya tool format, plus oracle labels and batch-1 latency.
Code, results and caveats: https://github.com/shro-2002/rewardshield

| Folder | Contents |
|---|---|
| `pools/` | E02 rollouts from the E01 warm-start adapter, 4 samples per question, T = 0.8: dev-A audit pool (1,360), training pool (4,728) |
| `sft_arms/` | the two verifier-filtered training sets (911 each): single-1-accepted and targeted-4-accepted samples |
| `eval_trajectories/` | greedy dev-A/dev-B trajectories for E00 (base), E01, E04, E05, E07, each with an `_oracle` file of test-suite oracle labels |
| `latency/` | per-episode wall-clock seconds at batch size 1, first 60 dev-B questions, one Kaggle T4, fp16 |
| `exploratory/` | union-oracle disagreements and flight_2 analysis rows (post-hoc, not pre-registered) |

Record fields: `qid`, `sample`, `final_sql` (last successfully executed query), `n_tool_calls`, `gen_tokens`,
`messages` (system, user, assistant, tool-result turns), decoding settings and adapter path.
