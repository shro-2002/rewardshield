Some may be truly equivalent to gold, so "accepted" is not automatically an error; the oracle has not scored them.

## E00: base model, greedy (2026-11-14)

Tiny Aya Global with no fine-tuning, AgentTune fallback tool prompt, batched rollouts (max 4 steps), T4 fp16. Labels from the rebuilt test-suite oracle (`oracle/ORACLE.md`).

| Split | Questions | Episodes committing executed SQL | Test-suite accuracy |
|---|---|---|---|
| dev-A | 340 | 252 (74.1%) | 163 (47.9%) |
| dev-B | 379 | 304 (80.2%) | 195 (51.5%) |

Of episodes that commit SQL, about 64-65% are oracle-correct. Most base failures are format failures (no parseable tool call), which the warm start targets. Batched-loop parity with AgentTune `rollout_fn` (greedy, 12 dev-A questions): 12/12 identical final SQL. Raw: `runs/E01_job/` (not committed; regenerated by the Kaggle job).

## E01: gold-trajectory warm start, greedy (2026-11-14)

LoRA r16 SFT on 1,497 gold trajectories from 73 train databases (schema-disjoint from dev-A, dev-B and the training pool), 150 steps × 16, seed 0, 3.40 M tokens, final logged loss 0.34. Same prompt, decoding and oracle as E00. Paired difference over questions, 95% bootstrap interval (10,000 resamples; `scripts/analyze.py arms`, base as arm a).

| Split | Committing executed SQL | Test-suite accuracy | Δ vs E00 (95% CI, question bootstrap) | Δ CI, schema bootstrap |
|---|---|---|---|---|
| dev-A | 274 (80.6%) | 210 (61.8%) | +13.8 pts [+8.5, +19.1] | [+8.9, +18.8] |
| dev-B | 320 (84.4%) | 226 (59.6%) | +8.2 pts [+3.4, +12.9] | [+4.2, +10.7] |

**Note (22:50):** E00 and E01 were generated before the stop-token fix (DECISIONS.md 22:50); E01's turns contain invented tool results. These numbers will be replaced by re-runs with the fixed loop and are not used for any comparison. Correct-given-committed also rose (dev-A 64.7% to 76.6%; dev-B 64.1% to 70.6%), so the gain is not only from fewer format failures. One seed only. E01 is the shared starting checkpoint for every SFT arm; it is a baseline, not a test of H1-H3. Raw: `runs/E01_sft/` (not committed; adapter on Kaggle as `rewardshield-e01-adapter`).
