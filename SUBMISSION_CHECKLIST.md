# Round 1 submission checklist

Deadline: **Nov 15 2026, 11:59 PM AoE = Nov 16, 5:29 PM IST.** Target: submitted by Nov 16, 12:00 IST.
Source: https://hackathon.lexsi.ai/rules and /submit (re-read 2026-11-14 01:37 IST).

## Form inputs
- [ ] Registered email (user to confirm registration before Nov 8 close)
- [ ] Abstract under 500 words
- [ ] HF model collection, public and un-gated, every repo public (adapters; quants if made)
- [ ] HF dataset collection, public: data, logs, trajectories, benchmarks, curated splits
- [ ] Write-up as HF Article (or GitHub README)
- [ ] GitHub repo with reproducibility notes
- [ ] Repos and models used, track, problem statements

## Rules
- [ ] Track 3 toolkits used together: AgentTune + AuditKIT
- [ ] Core model from permitted list: Tiny Aya Global
- [ ] More than one before/after metric
- [ ] Project deployed publicly by the deadline
- [ ] Optional: ROI comparison (self-hosted vs closed API)

## Required write-up sections (* on the template)
- [ ] Title + one-line claim
- [ ] Tracks + problem statements (with numbers)
- [ ] Abstract
- [ ] Headline before → after number
- [ ] Base model + method in one line
- [ ] Problem statement and approach; why this problem / real use case
- [ ] Hackathon repos used, how each was used, how they connect
- [ ] Models and licenses; base Aya model, config, quant, licence
- [ ] Datasets, benchmarks and licences; sources; train/test sizes and leak check
- [ ] Tool / task environments, trajectories [T3]
- [ ] Metrics and why; agentic trajectory metrics [T3]: task success, tool-call accuracy, latency
- [ ] Method / experiments; setup and hyperparameters per repo
- [ ] Results: same model before vs after table
- [ ] Limitations: known weaknesses
- [ ] With more credits: planned approach + expected before/after
- [ ] Artifacts: HF datasets collection, HF models collection, GitHub repo
- [ ] Documentation and reproduction: repo layout and run instructions
- [ ] Declaration of work done outside the hackathon
- [ ] Teammates tagged (solo)

## Recommended optional sections
- [ ] Pre-registered hypotheses, related work, threat model, judge check, CIs, negative results, samples, compute used, LLM usage statement
